Multi-Context Parallelism

The final egg cracked. 7.9× speedup with 8 HW contexts.

The NPU driver supports up to 16 hardware contexts — each with independent doorbell, command queue, and syncobj. Our C++ context pool dispatches inference requests concurrently, achieving near-linear throughput scaling. The daemon runs FLM for single-request latency; the context pool handles concurrent throughput.

Dispatch Profile

Where the 222ms went. And how we fixed it.

μs-accurate profiling revealed 99% of XRT dispatch time is kernel launch overhead, not compute. 112 dispatches per token × 1346μs each = 157ms.

XRT dispatch1,346 μs/call99% is launch+wait
Actual GEMM0.5-5 μsoverhead ratio: 2000×
CPU attention26 μs/layer<1% of total
LM head (OpenMP)6 mswas 67ms · 11× faster
Fix: M=32 batch24×amortizes NPU compute
