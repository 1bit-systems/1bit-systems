Architecture wins
✓TQ2 ternary format — 34 bytes per 128 weights (32×2-bit + 2-byte fp16 scale). Per-block scales.
✓No hipBLAS/rocBLAS — custom ternary-aware HIP C++ kernels only. Wave32 WMMA 16×16×16.
✓Bonsai-1.7B TQ2 — 1.6 GB .h1b + 1.2 GB .gguf sidecar. Runs on Radeon 8060S (gfx1151).
✓Zaya model support — hybrid CCA attention + MoE with EDA router. Integrated in zaya-llama.cpp.
✓K_packed=512 + per-block scales — 8× fewer dispatches. Per-block fp16 scale for numerical stability.
