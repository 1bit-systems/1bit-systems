Install

Build from source. One monorepo.

ROCm 7.2+ for Strix Halo (gfx1151). cmake + cargo. Kernels + server.

Build
cmake -B build -G Ninja -DCMAKE_HIP_ARCHITECTURES=gfx1151
ninja -C build rocm_cpp bitnet_decode
Run
export HSA_OVERRIDE_GFX_VERSION=11.5.1
./build/bitnet_decode model.h1b --text "Hello" 128
Server
cd rust && cargo build --release
./target/release/onebit --model model.h1b --port 13305
Convert
tools/gguf_to_h1b model.gguf
→ model.h1b + sidecar.gguf
