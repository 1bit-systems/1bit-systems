ZINC GPU model-conversion Mamba2

bong-water-water-bong · Jul 26, 2026 · 3 min read

Zyphra family complete — Zamba2 hybrids and ZR1 reasoning, all 1BP

tl;dr: Zyphra ships four architecturally distinct models across two families — Mamba2-hybrid SSM (Zamba2) and dense reasoning-tuned (ZR1). All four now convert cleanly through the 1BP pipeline and run end-to-end on ZINC GPU. ZR1-1.5B does 26 tok/s on a Strix Halo ZINC GPU.

Beyond Zaya

Zaya1 was the headliner — a 149 MB 8.8B parameter 1-bit model that fits in L2 cache. But Zyphra's other lines are worth attention. They publish three distinct architectures:

  • Mamba2-hybrid — Zamba2 family. State-space layers with attention injected every 6th layer. Mixes linear-complexity SSM with sparse self-attention.
  • Dense transformer (Qwen2 arch) — ZR1-1.5B. Standard decoder-only, but reasoning-tuned via long chain-of-thought. A different beast entirely from Zaya's 1-bit ternary.

The 1BP pipeline is model-agnostic — GGUF auto-detection means no config files, no architecture-specific branches at load time. But each family needed its own conversion path tested and the resulting 1BP validated end-to-end. Here's the complete status:

The Mamba2-hybrid path

Zamba2 is a Mamba2 architecture with sliding-window attention every 6th layer. The GGUF loader in src/gguf_zamba2_loader.cpp handles the mixed-layer topology — it reads the Mamba2 SSM blocks as a new rcpp_arch variant, routes the attention layers through the existing ZINC attention path, and maps the Mamba2-specific weight layouts into the 1BP tensor schema.

Three model sizes (1.2B, 2.7B, 7B) all share the same architecture with different depth/width. The loader handles all three from one code path.

The Zamba2 loader doesn't special-case per-model dimensions — it reads them from the GGUF header. One loader, three sizes. That's the point of being model-agnostic.

All three run on ZINC GPU today. NPU path is next — Mamba2 SSM layers need a different xclbin layout than the dense transformer kernels we've built so far.

ZR1-1.5B — 26 tok/s reasoning on ZINC

ZR1-1.5B is Zyphra's reasoning-distilled dense transformer. Based on Qwen2 architecture (so it reuses the existing dense transformer GGUF path), fine-tuned for long chain-of-thought. At 26 tok/s on the ZINC GPU, it's fast enough for interactive reasoning tasks — not blazing, but usable.

For comparison: that's on the same Strix Halo ZINC Vulkan backend that powers all our dense models. The 1BP comes in at 781 MB — small enough to load instantly from any SSD, no quantization at inference time.

The model is listed under DeepSeek in the catalog because ZR1 is a reasoning-distill, same family as DeepSeek-R1-Distill-Qwen-7B. But the weights are purely Zyphra.

Try it

$ curl -sL https://1bit.systems/install.sh | bash
$ 1bit pull zamba2-1.2b
$ 1bit serve 8081

Or clone and build from source:

$ git clone https://github.com/bong-water-water-bong/1bit-systems
$ cmake -B build && cmake --build build
$ ./build/zaya_server --model models/Zamba2-1.2B.1bp --port 8088

All four 1BP models are hosted on Hugging Face at huggingface.co/bong-water-water-bong.
